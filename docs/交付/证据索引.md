## 4. 复盘中的事实与判断

`at_time_facts` 和 `later_facts` 由程序从日志重算，读取时重新核对来源。`assessment`、`suggestion` 和在线 `reason` 是模型文字；即使 JSON、编号和引用归属通过，也可能有配牌、张数、牌张归属和时间先后错误。

`facts_verified=true` 只覆盖相应程序事实数组，不能推广到整段模型分析。程序补齐引用也不能替模型原文修复一个错误的 inline 引用。
