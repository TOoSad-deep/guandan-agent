# 掼蛋 Agent 实验报告

更新日期：2026-10-20。B10 三版本各一整场已完成，2,983 次提交全部得到平台确认。40 次真实模型请求使用 163,884 tokens，预算耗尽后的规则降级如实保留。样本不足以比较稳定胜率。

## 1. 问题与实现

研究问题是：在官方平台提供合法动作的条件下，现有大语言模型能否通过有限的 Agent 流程参与掼蛋决策，并以有限调用量保留完整执行证据。

系统由 OpenGuanDan 平台接入、按座位隔离的 Session、本人手牌工具、LangGraph 决策、校验兜底、记录与页面、离线复盘构成。模型只返回当前候选编号，程序决定是否提交。平台事实、程序计算事实和模型判断分开保存。没有训练或微调模型。

## 2. 对照配置

| 版本 | 决策方法 | 每步最大在线调用数 |
| --- | --- | ---: |
| V0 | 当前冻结规则和候选工具 | 0 |
| V1 | 工具辅助的一次主决策 | 1 |
| V2 | 与 V1 相同主决策，满足条件时一次复核或修复 | 2 |

V1/V2 的主模型、候选工具和兜底相同。复核条件为对手临近走完、使用炸弹、压过领先队友。拆牌风险阈值尚未验证，不启用。唯一合法选项可零调用执行。

冻结记录为 `artifacts/b10/frozen-plan.json`，配置为 `configs/b10-v0.toml`、`b10-v1.toml`、`b10-v2.toml`。共同使用 `b05-rules-v1` / `b05-candidates-v1` / `b02-cheap-v1` 和 `b09-facts-v3`，线上思考关闭。详细配置摘要和执行环境由该冻结清单给出。

## 4. 先前文本质量实验

该实验发生在 B10 之前，与本批整场对战结果分开。使用同一组 12 任务各重复 2 次，来自同一历史比赛的 9 个原请求。结构、动作归属和程序事实通过，与模型自然语言准确性分别审计。

| 指标 | 关闭思考 | High 实验 |
| --- | ---: | ---: |
| 实际调用/传输成功 | 24/24 | 24/24 |
| 生产契约通过 | 24/24 | 24/24 |
| 离线程序事实通过 | 12/12 | 12/12 |
| 文字未发现明确错误 | 14 | 21 |
| 文字明确错误 | 6 | 1 |
| 文字含混 | 4 | 2 |
| 总 tokens | 94,646 | 124,305 |
| Provider P95 | 4.67 秒 | 14.32 秒 |
| Provider 最大耗时 | 5.47 秒 | 39.96 秒 |

High 同时启用思考并将生成上限改为 8192 tokens、超时改为 90 秒，属于整套配置比较。High 仍把“打出两张 6”写成“拆掉 6 的一张”，并有两项含混表述和一项具体引用不精确。未提及的事实不能算作理解验证。详见[High 原报告](../High档24次对照复测.md)。

本地正式模型超时为 20 秒、决策总预算 30 秒。High 最慢单次调用 39.96 秒，不能将该实验的完成率套用到在线时限。线上评测保持冻结的生产参数。

## 5. 可复现性与交付验证

本批就绪检查为 965 项通过；批次脚本、审计和打包检查完成后的最终全量为 **1,030 passed（6.69 秒）**，见 `artifacts/b10/pytest-final.log`。Python wheel/sdist 构建通过。干净应用目录创建新虚拟环境后锁定安装成功，两份 Java JAR 重新构建成功。安装和构建复用了本机 uv/Maven 依赖缓存，因此证明的是新应用目录重建，不是完全无缓存或全新操作系统测试。

3 秒 V0 短演示得到 335 次提交与确认、0 次模型调用，随后受控中断并完整关闭，服务端口已释放。该 development/interrupted 演示不追加到三版本比赛成绩。证据为 `artifacts/b10/clean-demo.json` 与 `clean-install-verification.json`。交付包清单、摘要及扫描以 `artifacts/b10/delivery/` 的实际产物为准。

运行方法见[运行与交付说明](运行与交付说明.md)。指标应能由已关闭源日志重算；原始模型回复和失败样本保留，不能用编辑后的文本替换原记录。

## 6. 结论与限制

三版本完成真实整场，V2 自然复核确认链已覆盖；有限调用、规则降级、记录和统计流程均按冻结条件执行。已知的工程边界是：动作合法与平台确认由程序核验，模型解释仍可能出错。高档思考在固定归档样本中表现更好，同时增加耗时与 tokens；这一观察没有证明在线策略强度。

教师平台版本、外部 API 许可和真实单步时限尚未确认。小样本、非配对发牌、有限调用导致的规则降级和自然实局复核覆盖情况必须随结果披露。当前材料不宣称满足未发布的比赛条件，也不宣称模型策略优于规则基线。
