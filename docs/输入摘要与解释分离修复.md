# 输入摘要与解释分离修复

> 公开版本说明：本文中标为“原工作区”的材料未随仓库提供；可公开核对的内容见[证据说明](evidence/README.md)。

日期：2026-10-19。范围：针对15次复测的数牌、配牌、牌张归属错误，按审阅后的精简方案修改输入及展示；本轮真实模型调用0次。

## 已实现

1. **共享精确计数。** 将候选模块已有的多重集合扣牌和点数计数提取到 `hand/summary.py`，候选评分与模型摘要共用。保留同花色重复牌、小王和大王的独立身份；不新增组合搜索。
2. **明确本人实际配牌。** `hand_summary` 提供实体牌数量、各点数张数、实际配牌列表及数量。打3且本人没有H3时，配牌列表为空；H2不会被计作配牌。
3. **提供候选影响。** `effect` 提供交出牌及点数张数变化。普通出牌提供假设扣减后的手牌摘要；贡还只描述交出牌的影响，`projected_hand_after_play=null`。不把“2张变1张”直接判为策略不好，也不将 `split_cost` 等估计改为确定事实。
4. **精简模型输入。** 在线新提示最多保留最近6条公开动作，离线最多2条，压缩模式1条；原始与中文语义历史同步标记省略量。当前领牌、余牌数、完成顺序等请求状态保留。该条数是当前工程取值，未验证为最佳策略上下文长度。
5. **删除离线历史理由，压缩事后牌面。** 新离线提示不传 `recorded_judgment/model_judgments`。后续事件保留座位关系、动作牌型/点数/张数、局内顺序和整场胜方，但省略具体牌面；程序事实的提示副本同步省略，避免从另一段文字重新引入H3。完整原始记录和最终报告事实仍保留。
6. **展示事实与原文并列。** 决策详情新增只读 `program_explanation`，根据原请求和选中动作计算。页面标明“程序事实说明”和“模型原始理由 · 未核验”；不覆盖原理由、不宣称模型文字已核验，也不因解释问题额外调用模型。

模型输出仍为 `action_id + reason`，离线仍为原来的四个分析字段；没有引入理由类型枚举、通用中文事实检查器或额外反思循环。选择策略、风险触发、调用额度和提交权限保持原契约。

## 版本与兼容性

- 当前在线默认：`b09-facts-v3`；离线默认：`b09-offline-v3`。
- 保留b05、b07及在线/离线v2路径。显式历史配置仍按原版本执行；旧复测运行器继续固定v2。
- `local.example.toml` 与 `offline-facts.example.toml` 已更新；后者仍为0调用额度，默认check不发起任务。
- 最终报告的确定性事实生成保持兼容。ReportStore支持v2/v3，仍对照源记录重新核验。新增说明仅存在于读取结果中，不写回原对局。

事后信息仍会以摘要形式进入同一次离线调用；这是输入精简，不是严格的信息隔离。模型可以基于摘要讨论后续结果，但仍须区分当时与事后。
