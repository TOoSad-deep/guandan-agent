## 改动与边界

| 问题 | 当前处理 |
| --- | --- |
| SB/HR、红桃配牌、TwoTrips 等被误读 | 共享 `semantics.py` 从原始牌码和平台牌型生成中文语义，保留重复牌；只把当前级牌的红桃标为配牌 |
| back 被当作普通出牌，贡还后直接减一 | 明确出牌/进贡/还贡；换牌完成后的手牌与张数缺少证据时保持未知 |
| 队友、队伍级别、名次、胜方混淆 | 明确座位和队伍映射、级别与完成顺序的区别；结算胜方来自平台字段 |
| greaterAction=PASS 被解读为三家不出 | 明确它表示本次动作之前的领先状态，不据此推断其他玩家已经过牌 |
| 复盘模型编造事实段落 | 新离线输出只接受 request_id、证据编号、分析与建议；事实段落由程序从原记录生成 |
| 存档自称“已核验” | 读取层重算程序事实并比对文字及必要引用；不一致时标 partial，不改原文件 |
| 旧报告被误认为已修正 | 旧文字继续显示“模型归纳 · 未核验”；新程序事实、模型分析和建议分别标注 |

在线默认提示为 `b09-facts-v2`，主决策、复核、修复共享同一语义投影。公开历史裁剪时，原始历史与中文语义历史同步裁剪。候选编号、合法动作映射、调用预算及提交权限保持原契约。

离线默认提示为 `b09-offline-v2`。`at_time_facts` 仅含请求时可见信息，记录动作及其执行状态放入 `later_facts`。输入因预算缩减时，模型只能引用实际提供的事件；最终程序事实仍使用固定有界的完整投影，附上所需源事件编号。

`facts_source=program` 表示来源声明，`facts_verified` 由读取层依据源记录重算，不能由文件中的布尔值授权。核验只覆盖程序事实与源记录的一致性，**不覆盖模型分析正确性，也不证明策略更强**。旧报告默认 `facts_source=model`、`facts_verified=false`。
