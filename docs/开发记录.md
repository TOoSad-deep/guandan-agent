## 安装与本地检查

需要 uv、Python 3.12.13；Java 构建另需 JDK 21 和 Maven。Python 固定版本见 `.python-version`，完整依赖版本和来源见 `uv.lock`。

```sh
uv sync --locked --cache-dir runtime/uv-cache
uv run --locked --cache-dir runtime/uv-cache guandan-agent --version
uv run --locked --cache-dir runtime/uv-cache guandan-agent config-check configs/local.example.toml
uv run --locked --cache-dir runtime/uv-cache pytest
```

`config-check` 只读指定 TOML；内置默认值先应用，显式 `--model NAME` 最后覆盖。配置校验后冻结并生成规范 JSON 的 SHA-256 `config_id`。它不加载 `.env`、不连接平台、不调用模型。本地样例为四个 V0 座位，在线/离线额度默认 20/2；后续真实验证须按批次使用更小的冻结额度。

普通 pytest 禁止网络连接、使用本地固定输入，机器上已有密钥也不会触发模型请求。环境检查中的 FastAPI 路由只用于进程内兼容性测试，产品 HTTP 服务在 B08 实现。[uv 锁定安装说明](https://docs.astral.sh/uv/concepts/projects/sync/)；[FastAPI 进程内测试说明](https://fastapi.tiangolo.com/tutorial/testing/)。

## B02 模块交接

- `platform/`：`OpenGuanDanPlatform` 与 `ScriptedPlatform` 共用原帧解析和发送编码；`connect` 发起入局，`events()` 确认入局及逐帧交付，`write(intent, gate)` 紧邻发送前同步检查权限。单连接只建一个接收循环，不重连或重发。协议按固定源码实现，传输参数对照 [websockets 15.0.1 文档](https://websockets.readthedocs.io/en/15.0.1/reference/asyncio/client.html)。
- `hand/` 与 `strategy/`：`cheap_choice(state, legal)` 先确定备用动作，再建立 `RequestContext`；`DecisionPolicy.decide(DecisionInput(...))` 只返回建议。临时版本为 `b02-cheap-v1`，配置中的 policy/fallback 版本同步记录。完整去重集合唯一时直出；V0 正常选 rule，选择器异常使用已验证 fallback。B02 当时未接模型；当前 V1/V2 已由 B05/B07 接入。
- `recording/`：`await EventStore.create(...)` 建立新记录目录；`append` 分配序号并加入有界队列，`query(EventQueryScope(...))` 只查选定 run/session/seat；`await close(...)` 保存汇总。`ClosedRunLog.load(...)` 首次读取已有文件，查询不反复扫盘。缺口、残缺尾行与未知用量保持可见。

记录包含 `config.json`、`events.jsonl`、`summary.json`。关闭过程中使用 `summary.pending` 标记未确认关闭；正常完成才移除它。超时返回 `closed=false/log_complete=false` 并停止后续写入；已开始的汇总发布可能晚完成，但 pending 保留，读取器仍拒绝把该目录认作可信闭合源。不要手动删除标记把未完成记录变成成功。

## B03 运行闭环与入口

`Session.post()` 同步应用本座位事实，统一维护请求版本、一次提交资格、建议/提交两个截止和反馈确认。`TableState` 是 Session 私有的事实归约对象；历史窗口裁剪不改变阶段进度。计时器、迟到策略结果和发送回调都带原请求归属；写出不确定且连接不能继续使用时，整次运行受控中断并保留未知记录。

`RunManager.start/stop` 同步占用或撤销运行资格；连接、策略、发送与清理在异步任务中完成。创建房间的首个座位确认后才连接其他座位；多场使用新的 match/session ID。当前支持 V0/V1/V2；V2 支持历史 b07-review-v1、b09-facts-v2 及当前默认 b09-facts-v3 提示版本。默认配置注入冻结 ReviewConfig；历史 V0/V1 配置仍可沿用旧提示。

以下命令需先有本地官方 Java 服务监听配置中的地址；该入口已在 B04 完成一次新客户端真实整场验收：

```sh
uv run --locked --cache-dir runtime/uv-cache guandan-agent run configs/local.example.toml
```

日志保存到 `runs/<run_id>/`。按 Ctrl-C 可安全停止；开发短运行可显式附加 `--max-runtime-s 120`，到时结果为中断，不伪造比赛结算。`--startup-timeout-s` 默认 15 秒；`--recording-root` 可指定本地记录目录。`run_started` 保存有效配置与安装包源码摘要，成功解析帧的原始 JSON 按座位记录；单调时钟只在进程内使用，日志记录相对毫秒及预算来源。

```sh

uv run --locked --cache-dir runtime/uv-cache pytest tests/integration/test_b03_runtime.py
```

脚本端到端验收覆盖四座位、连续两场、六个反馈确认、停止及记录关闭；脚本只提供最小固定流程，不是新的掼蛋规则引擎。B03 为本地测试证据，下面的 B04 为实际平台证据。

## B05 候选工具与主 Agent

- 新版 V0/V1 共用 `b05-rules-v1` / `b05-candidates-v1`：计算本人余牌特征，保留合法 PASS、全部可走完动作和必要压制选项。达到硬上限或工具失败时用预先冻结的廉价备选。Java 子进程只分析本人余牌首出组合，结果用于估计，不能加入平台合法集合；故障后该 run 停用深评。
- Session 注册一次候选，维护窄 `CallPort`；四席和多场共用 run 额度。失败占用不退，实际开始前再次校验请求和期限。只有对应成功调用的主建议可登记，截止时可保留已登记的有效 main。
- V1 使用实际 LangGraph `main → route → finalize/fallback → END`，单次调用、零自动重试。Gateway 做信息白名单、输入字节限制、严格 JSON/候选校验；ProviderPort 只接收普通 messages、输出原始文本和用量，后续离线复盘可复用。

Provider 超时后仍未结束的本地任务继续占用并发名额；等待方按自身期限返回。迟到结果最多补未知用量，不恢复决策资格。运行结束由 Gateway 取消任务并关闭 Provider。

[V1 配置样例](../configs/b05-v1.example.toml) 仅给座位 0 配置 V1，模型额度为 0；B06 已另行冻结并完成真实短验证。`config-check`、导入模块和 V0 都不读取模型凭证；显式 V1/V2 运行只从进程环境获取 `DEEPSEEK_API_KEY`，缺失时在建立平台连接前失败，不主动读取 `.env`。
