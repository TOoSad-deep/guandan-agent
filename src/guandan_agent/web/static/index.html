模型复盘配置帮助

网页复盘使用 configs/web-review.toml 的模型与调用额度。将密钥配置在 .env，然后启动：

uv run --locked --env-file .env guandan-agent serve

可用 --review-config YOUR_CONFIG.toml 指定 configs 目录中的配置。每次点击只创建一份复盘，失败不自动重试。
